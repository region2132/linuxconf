## 什麼是 GitHub？

GitHub 讓開發者能夠在雲端儲存、分享以及共同協作他們的程式碼專案。它結合了 Git 的分散式版本控制功能與網頁介面的協作工具，讓團隊開發變得更加高效。

## 核心功能特色

* **版本控制**：完整記錄程式碼的每一次修改歷史，隨時可以回復到先前的版本。
* **團隊協作**：支援多人同時開發同一個專案，透過 Pull Request 審查與合併程式碼。
* **Issue 追蹤**：用於回報錯誤 (Bug)、提出功能建議與任務指派。
* **GitHub Actions**：內建的 CI/CD 自動化工具，可自動執行測試與部署。

## 基本運作流程

1. **Clone**：將遠端儲存庫複製到本機端。
2. **Commit**：在本機端修改程式碼並儲存變更記錄。
3. **Push**：將本機端的修改上傳回遠端 GitHub 儲存庫。
4. **Pull Request**：發起合併請求，邀請團隊成員審查程式碼。

## 常用名詞解釋

| 名詞 | 說明 |
| :--- | :--- |
| **Repository (Repo)** | 專案儲存庫，存放程式碼與檔案的地方。 |
| **Commit** | 提交，對程式碼進行一次儲存與快照。 |
| **Branch** | 分支，用於獨立開發新功能或修復錯誤，不影響主線。 |
| **Fork** | 複製別人的專案到自己的帳戶下進行修改。 |
